### 🛡️ Featured Engineering & Security Repositories

Here is a look at the actual core architectures and defensive concepts I have engineered:

#### [1. NextGen Residency (Smart Housing Society Portal)](https://github.com/alishba-1805/Smart-Housing-Society-Website)
> A production-grade, highly fortified full-stack MERN application featuring separate, secure operational gateways for Residents, Admins, and Vendors.
*   **Active Defense Hardening:** Built-in cryptographic **Token Fingerprinting** (binding JWT access/refresh tokens to specific client properties to block token hijacking/replay attacks).
*   **Client & API Mitigation:** Implemented `Helmet.js` custom security headers (strict HSTS, CSP, and XSS filtering), Double-Submit Cookie middleware for CSRF prevention, Express NoSQL injection scrubbers, and dynamic endpoint rate-limiters.
*   **Technologies:** React.js • Node.js • MongoDB • Express.js • JWT Security • HSL Custom Design

#### [2. Dizzy Walk Adventure Engine](https://github.com/alishba-1805/Dizzy-Walk)
> A retro RPG engine written entirely in raw x86 Assembly (MASM32) with direct Win32 GDI rendering, bypassing all high-level game engines.
*   **Low-Level Systems:** Dynamic obstacle parsing using structural memory grids ($20 \times 30$ dimension arrays), real-time keyboard interrupt capturing, raw PC-beep frequency modulation for game cues, and sequential assembly-level File I/O for real-time player telemetry logging.
*   **Technologies:** x86 Assembly • Win32 GDI • Low-Level Systems • Keyboard Registers

#### [3. Xonix Arcade Game Architecture](https://github.com/alishba-1805/Xonix-Game-)
> A fully object-oriented arcade system engineered in C++ that bypasses standard libraries in favor of custom, self-balancing data structures.
*   **Computer Science Engineering:** Implemented self-balancing Binary Search Trees (`LeaderboardAVL.h`) for instant leaderboard querying, Custom double-ended queues (`GameStateDeque.h`) to store frame-by-frame snapshots, and binary Min-Heaps (`MatchmakingHeap.h`) for prioritizing concurrent match queues.
*   **Technologies:** C++ • Object-Oriented Programming (OOP) • Custom Data Structures (DSA)

#### [4. SecureShop (E-Commerce System)](https://github.com/alishba-1805/SecureShop---E-Commerce-Management-System)
> A highly structured console-based C++ application designed within strict structural Programming Fundamentals (avoiding OOP and STL classes) to demonstrate lightweight cryptography.
*   **Cryptographic Layer:** Features mathematical Caesar Cipher byte shifts on user disk records to obfuscate persistent databases, a dynamic 6-digit OTP generator for simulated Multi-Factor Authentication, and password asterisk masking with lock-out handlers.
*   **Technologies:** C++ • Caesar Cryptography • File I/O Streams • Operational Logging

#### [5. Multi-Area Enterprise Network Design](https://github.com/alishba-1805/Multi-Area-Network-Design-Implementation)
> A full enterprise-scale network architecture mapped for secure segment communications.
*   **Network Security:** Structured VLSM address mapping, OSPF dynamic multi-area routing, rigid Firewall Access Control Lists (ACLs) to segregate traffic, and DHCP/DNS configuration audits.
*   **Technologies:** Cisco Packet Tracer • VLSM subnetting • OSPF • Firewall ACLs
